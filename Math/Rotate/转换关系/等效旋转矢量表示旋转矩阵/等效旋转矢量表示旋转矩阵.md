# 等效旋转矢量表示旋转矩阵

用旋转矢量 $\vec{\phi}$，代替旋转角度和单位矢量：

$$
\begin{aligned}
        \vec{b}
    =
        \left\{
                \boldsymbol{I}
            -
                    sin(||\vec{\phi}||)
                \cdot
                    \left(
                        \frac
                            {
                                \vec{\phi}
                            }
                            {
                                ||\vec{\phi}||
                            }
                        \times
                    \right)
            +
                    \left[
                        1
                        -
                        cos(||\vec{\phi}||)
                    \right]
                \cdot
                    \left(
                        \frac
                            {
                                \vec{\phi}
                            }
                            {
                                ||\vec{\phi}||
                            }
                        \times
                    \right)
                    ^2
        \right\}
    \cdot
        \vec{a}
\end{aligned}
$$
