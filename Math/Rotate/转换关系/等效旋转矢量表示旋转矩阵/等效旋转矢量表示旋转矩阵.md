# 等效旋转矢量表示旋转矩阵

用旋转矢量 $\vec{\phi}$，代替旋转角度和单位矢量。

在用几何方法研究定轴旋转时，是研究向量旋转。若向量不动，坐标系旋转则是反着的。

向量旋转 $a$ 到 $b$，等价于坐标系旋转 $b$ 到 $a$，即$C_b^a$：

$$
\begin{aligned}
        C_b^a
    =
            \boldsymbol{I}
        +
                sin(||\vec{\phi}_{系ba}||)
            \cdot
                \left(
                    \frac
                        {
                            \vec{\phi}_{系ba}
                        }
                        {
                            ||\vec{\phi}_{系ba}||
                        }
                \times
                \right)
        +
                \left[
                    1
                    -
                    cos(||\vec{\phi}_{系ba}||)
                \right]
            \cdot
                \left(
                    \frac
                        {
                            \vec{\phi}_{系ba}
                        }
                        {
                            ||\vec{\phi}_{系ba}||
                        }
                    \times
                \right)
                ^2
\end{aligned}
$$

$\vec{\phi}_{系ba}$ 表示在 $a$ 系下观察 $b$ 系的定轴旋转的等效旋转矢量。

所以省略上角标。
