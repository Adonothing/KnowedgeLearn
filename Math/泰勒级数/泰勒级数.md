# 泰勒级数

数学上，泰勒展开式是非线性方程线性化，将原来的曲线表示为多级数的线性和：

$$
\begin{aligned}
        f(x)
    =
        \sum
            _{0}
            ^{\infty}
        \left[
            \frac
                {
                    f^{(n)}(x_0)
                }
                {n!}
            \cdot
            (x - x_0)^n
        \right]
\end{aligned}
$$

一阶泰勒展开式为：

$$
\begin{aligned}
        f(x)
    =
        f(x_0)
    +
                {
                    f^{'}(x_0)
                }
            \cdot
            (x - x_0)
    + \cdots
\end{aligned}
$$

图像上应该这样理解，复杂曲线可以分解为简单多次函数的叠加。

如果取微分，可以这样理解，多次曲线拟合为复杂曲线。
