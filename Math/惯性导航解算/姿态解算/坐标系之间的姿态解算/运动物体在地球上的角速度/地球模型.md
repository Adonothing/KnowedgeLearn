# 地球模型

地球不是规则的球形，可以用椭球近似。

椭球（地球）半径为：

$$
\begin{aligned}
        R_M
    &
    =
        \frac
        {
            a
            \cdot
            (
                1
                -
                e^2
            )
        }
        {
            \sqrt
                {
                    \left[
                            1
                        -
                            e^2
                            \cdot
                            sin^2(\varphi)
                    \right]
                    ^3
                }
        }
    \\
        R_N
    &
    =
        \frac
        {
            a
        }
        {
            \sqrt
                {
                        1
                    -
                        e^2
                        \cdot
                        sin^2(\varphi)
                }
        }
\end{aligned}
$$

$R_M$ 和 $R_N$ 分别为子午圈半径和卯酉圈半径。

椭球长半轴 $a$，椭球模型第一偏心率 $e$。
对于 CGCS2000 椭球，$a = 6378137.0 m$，$e = 0.08181919104$。
