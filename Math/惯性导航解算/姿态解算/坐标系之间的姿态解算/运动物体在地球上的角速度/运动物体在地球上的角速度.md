# 运动物体在地球上的角速度

地球是椭球，在地球表面运动会产生角速度：

$$
\begin{aligned}
        \vec{\omega}_{en}^n
    =
        \left[
            \begin{matrix}
                    \frac
                    {v_E(t)}
                    {
                        R_N
                        +
                        h(t)
                    }
                \\
                \\
                    \frac
                    {
                        -
                        v_N(t)
                    }
                    {
                        R_M
                        +
                        h(t)
                    }
                \\
                \\
                    \frac
                    {
                        -
                        v_E(t)
                        \cdot
                        tan[\varphi(t)]
                    }
                    {
                        R_N
                        +
                        h(t)
                    }
            \end{matrix}
        \right]
\end{aligned}
$$

$R_M$ 和 $R_N$ 分别为子午圈半径和卯酉圈半径。

物体中心的位置：纬度 $\varphi(t)$、海拔高度 $h(t)$。

物体的速度：北向速度 $v_N(t)$、东向速度 $v_E(t)$。
