# 旋转矩阵的微分方程与陀螺仪

陀螺仪测量的角增量为，载体系 $b$ 相对于惯性参考系 $i$ 系的角增量（在 $b$ 系下的投影）。

载体的旋转矩阵的微分方程为：

$$
\begin{aligned}
        C_{i}^{b}(t)
    =
        C_{i}^{b}(0)
    \cdot
        C_{b(0)}^{b(t)}
\end{aligned}
$$

当前姿态由上一时刻更新而来：

$$
\begin{aligned}
        C_{i}^{b}(t)
    =
        C_{i}^{b}(t - 1)
    \cdot
        C_{b(t - 1)}^{b(t)}
\end{aligned}
$$

只有认为在很小一段时间内，旋转方向保持不变（定轴转动）才能求解。利用定轴转动的公式表达：

$$
\begin{aligned}
        C_{b(t-1)}^{b(t)}
    =
                \boldsymbol{I}
            -
                    sin(||\Delta\vec{\theta}_{ib}^b||)
                \cdot
                    \left(
                        \frac
                            {
                                \Delta\vec{\theta}_{ib}^b
                            }
                            {
                                ||\Delta\vec{\theta}_{ib}^b||
                            }
                        \times
                    \right)
            +
                    \left[
                        1
                        -
                        cos(||\Delta\vec{\theta}_{ib}^b||)
                    \right]
                \cdot
                    \left(
                        \frac
                            {
                                \Delta\vec{\theta}_{ib}^b
                            }
                            {
                                ||\Delta\vec{\theta}_{ib}^b||
                            }
                        \times
                    \right)
                    ^2
\end{aligned}
$$

那么这里的角增量 $\Delta\vec{\theta}_{ib}^b$ 就是陀螺仪输出的值。
