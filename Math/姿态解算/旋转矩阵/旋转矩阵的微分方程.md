# 旋转矩阵的微分方程

观察到旋转矩阵的导数等于一个包含旋转矩阵本身的一个方程。这是一个微分方程。

姿态函数可表达为：

$$
\begin{aligned}
        C_{a}^{b}(t)
    =
        C_{a}^{b}(0)
    \cdot
        C_{b(0)}^{b(t)}
\end{aligned}
$$

当前姿态由上一时刻更新而来：

$$
\begin{aligned}
        C_{a}^{b}(t)
    =
        C_{a}^{b}(t - 1)
    \cdot
        C_{b(t - 1)}^{b(t)}
\end{aligned}
$$

只有认为在很小一段时间内，旋转方向保持不变（定轴转动）才能求解。利用定轴转动的公式表达：

$$
\begin{aligned}
        C_{b(t-1)}^{b(t)}
    =
                \boldsymbol{I}
            -
                    sin(||\Delta\vec{\theta}_{ab}^b||)
                \cdot
                    \left(
                        \frac
                            {
                                \Delta\vec{\theta}_{ab}^b
                            }
                            {
                                ||\Delta\vec{\theta}_{ab}^b||
                            }
                        \times
                    \right)
            +
                    \left[
                        1
                        -
                        cos(||\Delta\vec{\theta}_{ab}^b||)
                    \right]
                \cdot
                    \left(
                        \frac
                            {
                                \Delta\vec{\theta}_{ab}^b
                            }
                            {
                                ||\Delta\vec{\theta}_{ab}^b||
                            }
                        \times
                    \right)
                    ^2
\end{aligned}
$$
